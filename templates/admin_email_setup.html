Add SMTP settings

  1. For Gmail, enable 2-Step Verification on a dedicated test account, then create an App Password under Google Account → Security → 2-Step Verification → App passwords. Google setup: Google App Password help ↗.
  2. In the Socio project folder, copy .env.example to .env. Set MAIL_SERVER=smtp.gmail.com, MAIL_PORT=587, MAIL_USERNAME to the full Gmail address, MAIL_PASSWORD to the App Password (remove its spaces), and MAIL_FROM to Socio <your-address@gmail.com>.
  3. Set MAIL_USE_TLS=1, MAIL_USE_SSL=0, DEV_EMAIL_PREVIEW=0, and PUBLIC_BASE_URL to the address you open Socio from. For local testing, use http://127.0.0.1:5001.
  4. Set a long random SECRET_KEY, save .env, then restart Socio. Never upload this file or share its values.
  5. Return here and send a test email to the signed-in platform administrator. Then create a fresh member account to check its confirmation email.

Email verification links are one-time links that expire after 24 hours. If SMTP is not configured, the localhost preview prints links to the server console.
